# Visual Reference

If `top-down-visual-reference.png` is present, it is the user-supplied visual
reference discussed during architecture design.

Use it only to understand structural presentation:

- top-down readability;
- 2D world;
- modest fake building depth;
- sprite-like vehicles;
- layered occlusion.

Do not copy proprietary game art, textures, logos or assets.

OpenGTA should create its own visual style and assets.
