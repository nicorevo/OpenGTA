# Codex Task Template

Copy this template for each non-trivial implementation task.

```text
TASK ID:
TITLE:

MODEL CLASS: ECONOMY | STANDARD | FRONTIER
REASONING: low | medium | high

GOAL:
One concrete outcome.

READ:
- exact documents/files required

MAY MODIFY:
- allowed paths

DO NOT TOUCH:
- unrelated modules
- architecture documents unless explicitly requested

CONSTRAINTS:
- relevant ADR/principles
- performance/security constraints
- no speculative features

IMPLEMENTATION NOTES:
- only confirmed details
- leave open decisions open

ACCEPTANCE:
- testable outcome 1
- testable outcome 2
- benchmark if relevant

BEFORE CODING:
1. inspect referenced code;
2. report conflicts with docs;
3. do not duplicate existing implementation.

AFTER CODING:
1. run relevant tests;
2. summarize changed files;
3. report assumptions;
4. report benchmark/result;
5. do not claim unrun tests passed.
```
