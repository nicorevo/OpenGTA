# Task FP-01: Camera 3D Config

## Descrizione

Creare il modulo `camera3d.ts` che definisce i parametri della camera prospettica:
- Field of View (FOV) di 60° (tipico guida arcade)
- Camera height di 1.5m (altezza occhio conducente)
- Near/far clipping plane (0.5m / 150m)
- Funzione di proiezione prospettica: `(worldX, worldY, worldZ) → (screenX, screenY, depth)`

Il modulo esporta una `CameraConfig` frozen e una funzione `projectPerspective()` che
applicano la proiezione prospettica standard (non orthografica).

## Acceptance criteria

- [ ] File `src/render/pixi/first-person/camera3d.ts` esiste e TypeScript passa
- [ ] `CameraConfig` interface con FOV=60, height=1.5, near=0.5, far=150
- [ ] `projectPerspective(x, y, z, camera)` restituisce `{ sx, sy, depth }` dove:
  - `sx` è normalizzato [-1, 1] (left→-1, right→1)
  - `sy` è normalizzato [-1, 1] (top→-1, bottom→1)
  - `depth` è [0, 1] (near→0, far→1)
- [ ] Coordinate: Z positivo = lontano dalla camera (lungo la road)
- [ ] La camera è posizionata a (0, cameraHeight, 0) e guarda lungo +Z

## Verification

- [ ] Unit test: `projectPerspective(0, 0, 10, config)` → centro schermo (sx=0, sy=0)
- [ ] Unit test: `projectPerspective(5, 0, 10, config)` → sx > 0 (destra)
- [ ] Unit test: `projectPerspective(-5, 0, 10, config)` → sx < 0 (sinistra)
- [ ] Unit test: `projectPerspective(0, 0, 0.5, config)` → depth=0 (near clip)
- [ ] Unit test: `projectPerspective(0, 0, 150, config)` → depth=1 (far clip)
- [ ] `npm run typecheck` verde
- [ ] `npm run test:run` verde (nessun test rotto)
