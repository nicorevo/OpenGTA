# Task FP-06: First-Person Renderer Orchestration

## Descrizione

Creare `first-person-renderer.ts` che orchestra i componenti e implementa
l'interfaccia `PixiRenderer`. Il renderer integra:
- Camera config (camera3d)
- Road projection (road-projector)
- Road drawing (segment-drawer)
- Building projection (building-projector)
- Sky (sky-drawer)

**Interfaccia PixiRenderer da implementare:**

```typescript
export interface PixiRenderer {
  readonly app: Application;
  render(chunk: CompiledChunkV0 | readonly CompiledChunkV0[]): void;
  setChunk(chunk: CompiledChunkV0): void;
  removeChunk(chunkId: string): void;
  presentationCounts(): { chunkPresentations: number; graphicsObjects: number };
  presentationDiagnostics(): { culledFeatures: number; facades: number; roadCasing: boolean; labels: number };
  setZoom(level: ZoomLevel): void;
  zoomIn(): ZoomLevel;
  zoomOut(): ZoomLevel;
  cameraState(): CameraState;
  updateVehicle(position: { x: number; y: number }, heading: number): void;
  toggleLabels(): boolean;
  cameraBounds(): Bounds2D;
  dispose(): void;
}
```

**Comportamento render():**
1. Pulisce il graphics object principale
2. Chiama `drawSky()` per il background
3. Per ogni chunk:
   - Chiama `projectRoadSegments()` per tutte le roads del chunk
   - Chiama `drawRoadSegments()` con i segmenti proiettati
   - Chiama `projectBuildings()` per gli edifici
   - Chiama `drawBuildingFaces()` con le facce proiettate
4. Il vehicle viene aggiornato con `updateVehicle()` (non disegnato - solo visuale dal parabrezza)

**Gestione dei chunk:**
- Usa solo i chunk attivi (stesso sistema di chunk loading)
- Per ogni chunk, filtra le roads che passano vicino alla posizione vehicle
- Le roads lontane (>500m) sono scartate prima della proiezione
