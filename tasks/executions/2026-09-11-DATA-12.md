## Risultato

Tile sintetiche (due tile adiacenti 14/9019+9020/6181, regione V0 a cavallo
del seam a +150 m) esercitano i quattro casi richiesti:

1. Strada che attraversa il bordo: una sola RoadFeature continua, ID
   canonico `mvt:transportation:123#p0`, centerline [-300, seam, +300]
   senza gap al seam.
2. Edificio a cavallo: due meta' disgiunte, nessuna sovrapposizione di area,
   area totale = 600 m x altezza reale (±5%).
3. Buco di poligono sul bordo: ogni meta' conserva la propria meta' del
   buco; area netta = esterno - buco (±5%), nessuna duplicazione.
4. Stessa feature bufferizzata nel vicino: la copia nel buffer del tile est
   viene eliminata (clip alla sola area propria del tile) -> una sola
   collisione/facade.

Meccanica implementata nel normalizer `src/geo/normalize/mvt.ts`:
- ogni tile contribuisce SOLO la propria area geografica (buffer scartato),
  intersecata con il box V0;
- le parti stradali dello stesso feature id vengono ricongiunte (endpoint
  entro 0,75 m) in catene deterministiche con ID canonici;
- poligoni con ID canonici `mvt:<layer>:<sourceId>#<suffix><n>`;
- output deterministico su run ripetute (test dedicato).
