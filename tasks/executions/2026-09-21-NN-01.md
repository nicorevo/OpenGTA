## Review del pipeline (reperimento → assegnazione → visualizzazione)

1. Reperimento MVT: join `transportation_name` per id OSM verificato su tile
   reale (script di audit su `src/fixtures/geo/lecce-z14-openfreemap.pbf`):
   585 transportation / 445 name, 0 id duplicati per layer, 151 strade
   nominate, 294 name senza drivable nel tile (buffer + classi non drivabili,
   atteso). Nessun join sbagliato.
2. Reperimento OSM: nome dai tag della way, senza join — corretto per
   costruzione.
3. Assegnazione (difetto): `compileRegion` (`compiled.ts:37`) = un label per
   way OSM; la via reale è fatta di più way con lo stesso `name`. Evidenze
   su tile reale: `Via Merine` = way 2030539842+2030544120 (entrambe
   secondary, frammenti contigui), `Viale Giacomo Leopardi` = 2921259582
   (minor) + 331908630 (primary), `Piazza Sant'Oronzo` = 2911607432+2911607442;
   più casing variante: `Viale venticinque luglio` (11370970572) accanto a
   `Viale Venticinque Luglio` (505127780/395278690).
4. Visualizzazione: dedup ND per identità di feature non mergea way distinte
   omonime → il nome appare una volta per way, su "vie completamente
   diverse".
