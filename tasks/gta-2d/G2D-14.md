# G2D-14: LOD e culling della profondita'

Stato: da fare. Persona: fullstack-developer. Taglia: M.
Dipendenze: [G2D-13](G2D-13.md).

## Obiettivo

Mantenere la resa stabile a distanza e sul mobile senza disegnare dettagli invisibili.

## Leggere prima

[Procedura comune](README.md), [spec](../../docs/specs/gta-2d-city-v1.md),
[analisi](../../docs/analysis/GTA-2D-VISUAL-GAP-2026-09-20.md),
file elencati sotto e log dei prerequisiti. I contratti nella spec precedono
le scelte di implementazione.

- `src/render/pixi/building-projection.ts`

Log e avanzamento piano/todo secondo la procedura comune. Geografia fisica,
controller, endpoint e gameplay aggiuntivo restano fuori da questa scheda.

## Esecuzione

Estendere il profilo con dettaglio materiali/facciate/props, conservando la separazione dalla fisica. Culling sui bounds proiettati con margine per l'ombra, non solo footprint. Aggiornare quando camera/zoom/viewport cambiano; evitare ricostruzione completa a ogni frame.

## Accettazione

- [ ] AC1: Un tetto o un'ombra visibile non scompare quando la base passa fuori viewport.
- [ ] AC2: Passaggi far/medium/near non cambiano materiale, identita', posizione o collider; nessun salto evidente durante resize.
- [ ] AC3: Su mobile il profilo riduce dettagli e costo mantenendo auto e carreggiata leggibili.

## Verifica

```bash
npm run test:run -- src/render/lod-profile.test.ts src/render/pixi/building-projection.test.ts
npm run test:e2e -- tests/e2e/gta-city.spec.ts tests/e2e/zoom.spec.ts --workers=1
```

Applicare anche il gate comune. Per la resa visiva verificare il fixture
con camera ripetibile, non soltanto la presenza degli oggetti nella scena.
